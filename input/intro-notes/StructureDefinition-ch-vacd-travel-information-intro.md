### Scope and Usage

This Condition profile is used to define travel information like

* Location: The country (and finer location definitions like region, city)
* Period: The time and duration the patient will stay at the Location

to be sent with an [Immunization Recommendation Request Message](immunization-recommendation-request-message.html) to a CDS System to receive an [Immunization Recommendation Response Message](immunization-recommendation-response-message.html) with [Immunization Recommendations](StructureDefinition-ch-vacd-immunization-recommendation.html) in the context of the travel destination.
